# Task Management System

A full-stack Task Management System built using Flask, MongoDB, HTML, CSS, JavaScript, and Bootstrap.

This application allows users to efficiently create, manage, update, search, filter, and track tasks through a responsive and interactive user interface.

## Functionalities

- Create new tasks
- View all tasks dynamically
- Delete tasks
- Update task status
- Mark tasks as Completed or In Progress
- Search tasks by title
- Filter tasks by status
- Progress tracking bar for completed tasks
- REST API integration
- MongoDB database connectivity
- Responsive Bootstrap-based UI

## Technologies Used

# Frontend
- HTML
- CSS
- Bootstrap
- JavaScript

# Backend
- Python Flask

# Database
- MongoDB

# CRUD Operations

The project implements full CRUD functionality:

- **Create** → Add new tasks
- **Read** → Fetch and display tasks
- **Update** → Change task status
- **Delete** → Remove tasks

## Additional Features

- Real-time task rendering
- Dynamic progress calculation
- Search and filtering system
- Modern responsive interface
- Frontend-backend API communication
